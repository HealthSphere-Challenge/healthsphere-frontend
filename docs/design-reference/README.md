The missing Downloads filenames are not proof these files are identical copies. Do not rename or replace originals to resolve that uncertainty.

## Precedence

User-approved scope/architecture and safety constraints govern. Phase 0 identity anchors visual decisions; Phase 1 extends it. [Design system](../ux/DESIGN_SYSTEM.md) distinguishes observations from proposed tokens. Static reference text is not application logic or permission to implement extra features.

The references include Google sign-in, forgot password, child supervision, health statuses, percentages and decorative effects. Track these as reference-only or unresolved rather than silently implement OAuth, guardian access, medical thresholds, fixed scores or emoji icons. Model results must come from the AI service through the backend.

## Source handoff gaps

Before implementing reusable artwork, establish approved logo/illustration exports and their permitted use. Extracting assets must preserve originals; do not invent a replacement brand. Exact fonts and responsive states require an approved implementation decision. Source PDF screens are images, not existing React components.
