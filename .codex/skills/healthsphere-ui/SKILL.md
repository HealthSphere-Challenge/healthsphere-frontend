## Workflow

Inspect existing components and the actual reference pages before planning a screen. Separate observed design evidence from unresolved tokens; do not silently pick a new font, brand or icon language. Identify reusable primitives and write a screen/state plan tied to the ticket. Preserve English copy and one-account/one-profile scope. Treat persona layouts as adaptation references, not guardian permissions or clinical rules. Implement only after the ticket/plan is authorized; provide reference comparisons and state/responsive evidence for review.
